Python Basics

1. Print & Variables

# Print to console
print("Hello, World!")

# Variables do not need explicit types
name = "Samuel"
age = 21
is_dev = True

2. Data Types

  • str : Text ("hello")
  • int : Integer (42)
  • float : Decimal (3.14)
  • list : Ordered items [1, 2, 3]
  • dict : Key-value pairs {"name": "Samuel"}

3. Loops

# For loop
for i in range(5):
    print(i)

# While loop
count = 0
while count < 5:
    print(count)
    count += 1

4. Functions

def greet(name):
    return "Hello, " + name

print(greet("DebugMate"))
Tip: Use pip install <package> inside the DebugMate Terminal to add third-party libraries.
