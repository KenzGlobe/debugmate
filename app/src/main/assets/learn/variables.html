Variables

Think of a variable as a labeled box in the computer's memory. You put data inside the box, give it a name, and later you can look inside the box to get the data or replace it with something new.

Why do we need them? Variables allow us to store, reuse, and manipulate data dynamically. Instead of hardcoding a value like 21, we store it in age and use age throughout the program.

1. Declaration vs. Initialization

  • Declaration: Creating the variable and giving it a name (and a type, in some languages). You are just reserving the box.
  • Initialization: Putting the first piece of data into the variable. You are filling the box.
# Python
name = "Samuel" # Declared and initialized at the same time

# Java
int age;       // Declaration (empty box)
age = 21;      // Initialization (filling the box)

2. Data Types

Computers need to know what kind of data is inside the box. Here are the most common types:

Type Description Example
String Text (letters, numbers, symbols) "Hello"
Integer Whole numbers 42
Float / Double Decimal numbers 3.14
Boolean True or False true
List / Array A collection of items [1, 2, 3]

3. Statically vs. Dynamically Typed

Different languages handle types differently:

Dynamically Typed (Python, JavaScript)

You don't need to specify the type. The computer figures it out based on the value.

x = 10      # x is an integer
x = "Hello" # Now x is a string (Allowed!)

Statically Typed (Java, C++)

You must specify the type when declaring. It cannot change later.

int x = 10;      // x is an integer
x = "Hello";     // ERROR! Cannot put text in an integer box.

4. Naming Conventions

You can name a variable almost anything, but there are strict rules and best practices:

  • Must follow: Can only contain letters, numbers, and underscores (_).
  • Must follow: Cannot start with a number (e.g., 1name is invalid).
  • Must follow: Cannot be a reserved keyword (like if, for, class).
  • Best Practice: Use meaningful names. user_age is better than x.
  • Best Practice: Use snake_case in Python (e.g., my_variable), and camelCase in Java/JS (e.g., myVariable).

5. Scope: Where do variables live?

Variables are not visible everywhere. Their "scope" determines where they can be used.

Local Variables

Declared inside a function or block. They can only be used inside that block.

def my_function():
    local_var = 5
    print(local_var)

my_function()
print(local_var) # ERROR! local_var doesn't exist out here.

Global Variables

Declared outside of any function. They can be accessed anywhere in the program.

global_var = 10

def my_function():
    print(global_var) # Allowed!

my_function()

6. Mutability (Constants)

Sometimes you want to create a variable that cannot be changed once it is set. These are called Constants.

// Java
final double PI = 3.14159;
// PI = 4.0; // ERROR! You cannot change a final variable.

# Python (Convention: UPPERCASE means constant)
MAX_SPEED = 100
# Python doesn't strictly enforce constants, but it's a rule developers follow.
