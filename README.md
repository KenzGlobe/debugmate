# DebugMate

**A mobile development workspace for coding, managing projects, and
learning programming on Android.**

DebugMate is an Android application designed to make programming and
project management more accessible from a mobile device. It combines a
code editor, project manager, file manager, learning resources, and
additional developer tools in one application.

## Features

### 1. Project Management

-   Create new projects from scratch.
-   Open existing projects.
-   Rename and delete projects.
-   Automatically generate project structures.
-   Access project dashboards, statistics, and quick actions.

### 2. Project Templates

DebugMate provides templates for different types of development:

  Category   Available Template
  ---------- --------------------
  Android    Empty Activity
  Web        Basic Web
  Python     Python Script
  General    Empty Project

The Android project generator currently supports the Empty Activity
template.

### 3. Code Editor

A built-in code editor powered by the Ace Editor engine.

Features include: - Syntax highlighting. - Line numbering. -
Auto-indentation. - Code completion. - Find and replace. - Undo and
redo. - Multiple file editing. - File tabs. - Copy, cut, and paste. -
Search within files. - Customizable editor settings.

**Supported languages:** - Java - XML - Python - HTML

### 4. File Manager

Manage project files and directories directly within DebugMate.

-   Create files and folders.
-   Copy and move files.
-   Rename files and folders.
-   Delete files and folders.
-   Share files.

### 5. Built-in Developer Tools

-   Terminal interface.
-   Python console.
-   Custom coding keyboard.
-   Built-in WebView browser.

Some tools, including the Python console and browser, require an
internet connection.

### 6. Learning Hub

Access programming learning resources covering:

-   HTML
-   CSS
-   JavaScript
-   Python
-   Java
-   Git
-   Linux

### 7. Programming Cheat Sheets

Quick-reference materials for supported programming languages and
development concepts.

### 8. Customization

Configure the application and editor to suit your workflow, including
available editor themes, font size, word wrapping, and other settings.

## Offline Support

DebugMate is designed to support mobile development workflows even when
an internet connection is unavailable.

Core project-management, file-management, and code-editing features can
be used offline. However, certain optional tools and features depend on
internet access.

## Getting Started

### Download

DebugMate's APK distribution will be provided through the project's
GitHub Releases page once a release has been published.

**[View GitHub
Releases](https://github.com/KenzGlobe/debugmate/releases)**

### Build from Source

1.  Clone the repository:

    ``` bash
    git clone https://github.com/KenzGlobe/debugmate.git
    ```

2.  Open the project in Android Studio.

3.  Allow Gradle to synchronize the project.

4.  Build and run the application on a compatible Android device or
    emulator.

## Current Limitations

Some capabilities are not currently supported:

-   Importing existing projects is not available.
-   Project storage locations cannot currently be customized.
-   Android project generation currently supports Empty Activity only.

These limitations may change in future releases.
